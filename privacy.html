Privacy Policy

This policy covers Personal Photo Backup, a private tool used only by its owner.

Google data it accesses

With the owner's permission, the tool uploads the owner's photos and videos to the owner's Google Photos account, creates albums, and adds items to the albums it created. It does not read the rest of the owner's Google Photos library or any other Google data.

How it uses that access

Only to back up the owner's own photos and videos to the owner's own account, and to organize them into albums.

What it stores

A record of which items it has uploaded and which albums it has created, kept on the owner's own hardware so that nothing is sent twice. It stores no other Google data.

Sharing

The tool shares no data with anyone. Nothing is sold, used for advertising, or sent to any third party.

Google API Services User Data Policy

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google Account's third-party connections page.
